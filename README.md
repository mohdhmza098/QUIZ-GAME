# 🧠 Quiz Game

An interactive **Quiz Game** built using **HTML, CSS, and JavaScript**.
The game presents multiple-choice questions, checks the selected answers, and keeps track of the player's score dynamically.

## 🛠️ Technologies Used

* **HTML5** — Structure of the quiz
* **CSS3** — Styling and layout
* **JavaScript** — Quiz logic and interactivity
* **DOM Manipulation** — Dynamic question and option rendering
* **Event Handling** — Handling answer selection and button clicks

## ✨ Features

* 📝 Multiple-choice quiz questions
* 🔄 Dynamically displays each question
* 🎯 Answer validation
* 📊 Real-time score tracking
* ✅ Shows final score after completing the quiz
* ⚠️ Alerts the user if no option is selected
* 🔒 Disables the button after quiz completion

## ⚙️ How It Works

1. A question with four options is displayed.
2. The user selects an option.
3. JavaScript checks the selected answer.
4. The score is updated if the answer is correct.
5. The next question is displayed automatically.
6. After all questions are completed, the final score is shown.
